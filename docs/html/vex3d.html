Vex3D 1.0.0 — tiny 3D

Сцены, объекты, софтверный растеризатор. Без движков снаружи: Win32 + GDI DIB + математика руками.

@ Vex3D
@ s : scene # 320, 200, "cube"
@ m : cube #
@ o : spawn # s, m, 0, 0, 5
color # o, 16744448

& step :
  turn # o, (tick # s), ((tick # s) * 2), 0
  ? tick # s > 300 :
    = fail
  !
    = open # s
  .
.

> frame # s, "step"

Как Юнити, честно спроецировано

ЮнитиVex3D
Scenescene # w, h, title
Instantiate + Meshcube # / mesh # flatvec + spawn # s, m, x, y, z
Transformmove / turn / scale / color
Update loopframe # s, "step" — мокро дальше, сухо стоп
Input pollingkey # s, code

Нет префабов, физики и материалов — это roadmap, не заявление. Углы — чистые функции tick (инструменты не пишут глобалы, так что тик и есть память).

Конвейер

Эйлер X→Y→Z (градусы), масштаб, перенос; камера смотрит +Z (поворота камеры нет); перспектива; плоский шейдинг по нормали; z-буфер; барицентрическая заливка в DIB. draw # s — один кадр без цикла (так тесты читают пиксели: getpx).

Осторожно: жадные призывы

Вложенные призывы в списках через запятую — в скобки (turn # o, (tick # s), ...), иначе внутренний съест хвосты. Подробно: язык.
