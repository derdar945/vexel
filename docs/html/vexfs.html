VexFS 1.0.0 — файлы

Нативный оператор, Win32, пути в UTF-8. Пять глаголов, без сюрпризов.

@ VexFS
> write # "note.txt", "line1\nline2"
> read # "note.txt"
> exists # "note.txt"
> dir # "."
> remove # "note.txt"

Глаголы

ГлаголСмысл
read # pathвесь файл текстом. Нет файла — fail. UTF-8 BOM срезается, лимит 64 МБ
write # path, textзаменить файл целиком → 1, иначе fail
dir # pathвектор имён (без ./..), плохой путь — fail
exists # path1 / 0 (никогда не fail)
remove # path1, не вышло — fail

Относительные пути — от cwd скамьи. Кириллица работает.

Ошибки — значениями, как обычно

> read # "nope.txt" ?? "empty"
> remove # "nope.txt" ?? "already gone"

Откуда ставится

!vex_add VexFS
!vex_info VexFS
