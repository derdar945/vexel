Vexel — верстак с метками

Маленький язык: смысл как в C, лёгкость как в Python, вид — свой. Плюс расширяемая экосистема операторов.

30 секунд до первой программы

> "Hello, vex!"
Hello, vex!

Запуск:

build.bat
vexel.exe !vex_run hello.vx

Идея за 7 строк

Каждая строка начинается с метки-руны. Программа — верстак, выполняется сверху вниз, отдельного main нет:

@ x : 12
? x > 10 :
  > "big"
!
  > "small"
.
* 3 :
  > it
.
& add a b :
  = a + b
.
> add # 2, 3
> risky # 0 ?? 0 - 1
МеткаСмысл
@ячейка — @ x : 10; оператор — @ VexGUI
>показ наружу (печать)
? ! .развилка вместо if/else
* .круг вместо for/while, it — номер круга
& .инструмент (функция)
=отдача результата (внутри инструмента)
#призыв: add # 2, 3 (без скобок)
??подхват: fail заменяется правым боком
;заметка (комментарий)

Карта документации

  • Язык и метки — значения, биты, развилки, круги, инструменты, fail.
  • CLI — все 16 команд !vex_* с примерами сессий.
  • Операторы и менеджер — формат .vxop, установка, зависимости.
  • Призывы со скамьи — как код вызывает операторы.
  • Native ABI — контракт для C-операторов.
  • Свой оператор — путь за 6 шагов.
  • VexGUI, VexFS, VexExec — три shipped-оператора.
