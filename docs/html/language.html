Язык и метки

Полное описание Vexel: программа, значения, все 7 видов строк, выражения, области, ошибки.

1. Модель программы

Файл .vx — это верстак. Выполняется сверху вниз. Точки входа main нет, обёрток нет, точка с запятой и фигурные скобки запрещены самой грамматикой. Пустая программа (одни заметки) — валидна и ничего не делает.

Блоки открываются двоеточием : в конце строки и закрываются точкой . на отдельной строке. Отступы значения не имеют. Перевод строки — граница тока: почти всё, что может висеть между строками, запрещено (например, аргументы призыва # живут строго на одной строке).

2. Значения — одна сущность, четыре лика

Вместо int/float/bool/string/array — одно значение с четырьмя ликами:

ЛикПримерыЗаметки
число10, 3.5, .5всегда f64; целые печатаются без точки
текст"vex", "a\nb"UTF-8, escapes \n \t \" \\
вектор[10 20], [], [1, "a"]пробел и запятая равнозначны; смешанные типы можно
failfail, 10 / 0рухнувшее значение (см. §7)
Правда — это влажность. Сухие: fail, 0, "", []. Всё остальное мокрое. Отдельного типа «булево» нет — and/or/not отдают 1/0.

3. Ячейки — @

@ x : 10
@ y : 32
@ x : x + 1

Первая запись куёт ячейку, повторная — обновляет. Внутри инструмента @ — локальная ячейка (параметры + свои), снаружи — глобальная. Вложенные круги и развилки новых областей не создают. Неизвестное имя — ошибка компиляции:

vexel: 1:3: unknown cell '@ nope' — forge it first

4. Показ — >

> x + y * 2
> "sum: " + str # x

Снимает значение и печатает: числа — 14/2.5, тексты — как есть, векторы — [10 20 30], fail — словом fail.

5. Развилка — ? ! .

@ x : 12
? x > 10 :
  > "big"
!
  > "small"
.
? x == 12 :
  > "twelve!"
.

? считает влажность условия. Мокро — верхняя часть, сухо — нижняя после ! (может отсутствовать). Вложенность свободная. Незакрытая развилка — ошибка с указанием строки.

6. Круг — * .

* 4 :
  > it * it
.
0
1
4
9

Счёт вычисляется один раз: число → int(e) (отрицательное → 0), fail → 0, мокрое-не-число → 1. it — номер круга от 0; вложенный круг затеняет внешний. Вне круга it читается как fail.

Круг — счётный. «Крутить, пока открыто» им не выразить — для долгих дежурств (цикл сообщений GUI) оператор даёт свой бег: run # w, "step" в VexGUI.

7. Инструменты — & . и отдача =

& add a b :
  = a + b
.
& fact n :
  ? n <= 1 :
    = 1
  !
    = n * fact # n - 1
  .
.
> add # 2, 3
> fact # 5

Параметры — через пробел, без скобок и запятых (& clock : — ноль параметров). = e мгновенно отдаёт e зовущему; без = инструмент отдаёт fail. = живёт только внутри инструмента. Призыв: имя # a1, a2, ноль аргументов — имя #. Инструмент должен быть выкован выше первого призыва; перековка — ошибка; рекурсия разрешена.

Встроенные (перекрываются своими &):

ГлаголСмысл
len # xдлина вектора/текста, иначе fail
at # v, iэлемент / символ (текст длины 1), мимо — fail
type # x"number" / "text" / "vec" / "fail"
str # xтекстовое отображение

8. Выражения и приоритеты

От слабого к сильному: ?? → or → and → == != → > < >= <= → + - → * / % → not, унарный - → призыв # → первичное. Скобки ( ) и векторы [ ] — как обычно, внутри них переводы строк разрешены.

  • +: число+число — сумма, иначе конкатенация отображений.
  • - * / %: числа ("ab" * 3 — повтор); деление/мод на ноль — fail.
  • == !=: любые лики, глубоко (fail == fail — мокро).
  • > < >= <=: только числа, иначе fail.
  • and/or — жадные (оба бока считаются), not — инверсия влажности.
  • f # a ?? b — это (f # a) ?? b: аргументы призыва останавливаются перед ??. Чтобы протащить подхват внутрь — скобки: f # (a ?? b).

9. Ошибки — fail и ??

& risky d :
  = 100 / d
.
> risky # 0 ?? 0 - 1
> at # [1], 9 ?? "empty"

try/catch/throw нет. Рухнувший ток — значение fail: течёт дальше (fail + 5 → fail), молчит, лечится якорем a ?? b (правый бок ленивый, цепочки a ?? b ?? "берег" — можно). Проверка: type # x == "fail".

10. Голый ток

Строка-выражение без руны вычисляется, результат выбрасывается — так зовут ради эффекта:

set_text # hello, "Hi!"

11. Полный пример

; cells, ask, loop, tool, vec, rescue — весь язык на одной скамье
@ c : [10 20 30]
> len # c
* len # c :
  ? at # c, it > 15 :
    > at # c, it
  !
    > "small"
  .
.
& double x :
  = x * 2
.
> double # 21
> at # c, 99 ?? "сухо, вброд"
