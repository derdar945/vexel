CLI — всё через !vex_

Фирменный префикс. В обычном Windows CMD восклицание — буквальный символ: vexel.exe !vex_run main.vx работает как есть.

1. Скамья: run / check / build / repl

КомандаСмысл
!vex_run <file.vx|file.vxb>выполнить
!vex_check <file.vx> [-v]только lex/parse/compile; -v — дизассемблер
!vex_build <file.vx> [out.vxb]байткод VXB2 (старые VXB1 грузятся)
!vex_replинтерактив (сессия переигрывается; bye — выход)
!vex_version / !vex_helpверсия / помощь

2. Проекты и операторы

КомандаСмысл
!vex_new <Project>каркас с main.vx
!vex_add <Operator>установить по имени (+ зависимости)
!vex_remove <Operator>удалить (отказ, пока нужен другим)
!vex_update <Operator>переустановить из источников
!vex_listустановленные
!vex_info <Operator>манифест + глаголы
!vex_search <term>поиск по хранилищу и исходникам
!vex_operator_new <Op>шаблон: манифест + C + пример
!vex_operator_build [dir]собрать entry-DLL (нужен gcc)
!vex_operator_install <dir>установить явный каталог
!vex_registry_add <dir|http>добавить источник операторов
!vex_registry_listисточники
!vex_registry_remove <dir|http>убрать источник

3. Цех: fmt / lint / test / debug / lsp

КомандаСмысл
!vex_fmt <file.vx> [-w]ровные отступы; -w — перезапись
!vex_lint <file.vx>статика без запуска (0 чисто / 1 ворчит / 2 бито)
!vex_test <file.vx>прогнать & test_*, мокро — PASS
!vex_debug <file.vx>шаг по VM: s r g v d q
!vex_lspstdio-сервер для редакторов

vexel.exe !vex_run examples/gui_hello.vx

vexel.exe !vex_add Nope

Для .bat-файлов: держите delayed expansion выключенным (иначе ! съедается) и CRLF-окончания строк (иначе cmd прыгает по файлу). Обе грабли реально встречались в этом проекте.
