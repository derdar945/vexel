VexGUI 1.0.0 — окна по-векселовски

Первый большой оператор. Только Win32 (user32/gdi32), без Qt/Electron/SDL/браузеров. DLL ~60 КБ.

1. Установка и первая скамья

vexel.exe !vex_operator_build operators/VexGUI   (build.bat уже собрал)
vexel.exe !vex_add VexGUI
vexel.exe !vex_run examples/gui_hello.vx
; gui_hello.vx — окно, заголовок, текст, кнопка, ввод, клик, закрытие
@ VexGUI

@ w : window # "Vexel — hello", 420, 260
@ hello : text # w, "press the mark", 20, 20
@ name : input # w, 20, 60
@ go : button # w, "Say hello", 20, 110

& step :
  ? clicked # go :
    @ who : get_text # name ?? "tide"
    set_text # hello, "Hello, " + who + "!"
  .
  = open # w
.

> show # w
> run # w, "step"

> "bye"

2. Философия событий: без слушателей

Оператор владеет циклом сообщений, Vexel владеет шагом. run # w, "step" качает сообщения и каждый раунд призывает инструмент step: ответ мокрый — крутим дальше, сухой — приземлились. Закрытие окна читается как сухость, поэтому круг приземляется сам — отдельный обработчик закрытия не нужен (хотя close # w разрушает по требованию).

Почему не обычный цикл *? Круг Vexel — счётный, «крутить, пока открыто» им не выразить. Бег run — честное архитектурное дополнение, а не костыль.

3. Все глаголы

ГлаголСмысл
version #"1.0.0" — окна не нужно
window # t, w, hхендл; скрыто до show
show # w1 — показать
open # w1 живо / 0 закрыто (качает сообщения)
close # w1 — разрушить сейчас
run # w, "step"1 — цикл до сухости шага или смерти окна
text # w, s, x, yподпись (STATIC)
button # w, s, x, yкнопка
input # w, x, yстрока ввода (EDIT)
editor # w, x, y, ww, hhmultiline editor with scroll
list # w, x, y, ww, hhlistbox
list_set # h, vecrefill the listbox from a vec of texts
selected # hchosen row text, fail if none
set_text # h, s1
get_text # hтекст
clicked # h1 один раз за нажатие (кнопка)
changed # h1 один раз за правку (ввод)
size # w[w h] — клиентский вектор

Хендлы — обычные числа. Кривые хендлы поднимают fail (кроме open — он читает мёртвое окно как 0):

> close # 999 ?? "no window"
no window

4. События: click, change, close, resize

; gui_events.vx — все четыре
& step :
  ? clicked # quit :
    close # w
  !
    ? changed # field :
      set_text # status, get_text # field
    .
  .
  = open # w
.

Resize виден через size # w (опрашивай в step и сравнивай с прошлым). Панели, Canvas, List, Menu, Dialog, темы и анимации — roadmap: их просто пока нет, заглушек нет.

5. Проверено живым окном

Тест tests/operators/gui_window.ps1 находит настоящее окно по заголовку, шлёт BM_CLICK настоящей кнопке, читает STATIC (Hello, !), закрывает и ждёт bye с кодом 0. Никаких моков.
