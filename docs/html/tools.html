Shop tools

Маленькие команды вокруг скамьи: форматтер, линт, тесты, отладчик, бенчи, LSP.

!vex_fmt — форматтер

Ровняет отступы (2 пробела на блок), режет хвостовые пробелы. Строки, комменты и скобки лексятся по-настоящему. Без -w — в stdout, с -w — перезапись. Идемпотентен.

!vex_lint — статика без запуска

Exit 0 чисто, 1 предупреждения, 2 битый файл: непрочитанные ячейки, всегда-мокрые/сухие развилки, круги на 0, пустые ветки, константное деление на ноль, тень встроенных имён.

!vex_test — ассёрты как инструменты

Гоняет main как сетап, потом каждый & test_* без марок: мокро — PASS. См. tests/core/t_testdemo.vx.

!vex_debug — машинный отладчик

Шаг по инструкциям настоящей VM, ячейки и стек наружу: s N, r, g, v, d, q. Им же гонялся само-хостный лексер.

!vex_lsp — языковой сервер

JSON-RPC поверх stdio: initialize, didOpen/didChange, hover, completion, definition, documentSymbol. Диагностика — ровно ошибки компилятора. Детали: docs/lsp.md.

benches/ — самозамер

fib(22), 200k кругов, 50k призывов; время — через time_ms # из VexSYS. Компилятор сворачивает чисто-числовые поддеревья, так что меряется VM.
